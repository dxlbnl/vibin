status: draft

Some tasks want a **conversation**, not a document. An agent and the human reason together toward acceptance
criteria — no spec-writer emitting a book first ([pain P5](../research/vibin-painpoints.md)).

- The conversation is **scratch** ([the run log](the-run-log.md)) — it dies with the session.
- What survives is whatever it produces: acceptance criteria, a [decision](the-atom.md), or a
  [rule](the-rules.md). If it settled something durable, **capture it** ([capture](capture.md)); otherwise it
  leaves nothing, by design.
- Resumability comes from the captured knowledge, not from replaying the chat.

**Why:** filing a one-sentence idea as a typed card → spec-writer → 587-line book is the friction you named. A
conversation is a first-class way to run [the loop](the-loop.md) for low-ceremony work.
