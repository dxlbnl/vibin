A small knowledge wiki *about what Vibin should become*, built in the shape Vibin itself should use: short,
single-idea notes ("atoms"), densely cross-linked into a graph. Start with [what Vibin is](what-vibin-is.md),
then [the loop](the-loop.md) and [the work loop](the-work-loop.md).
