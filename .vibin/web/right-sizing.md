---
title: Right-sizing (ceremony to match the stakes)
type: principle
status: draft
---

Ceremony is **proportional to risk**, chosen automatically — the smallest useful output.

- **Light path (default)** — clear, reversible work: acceptance criteria + tests, no spec page, no approval
  delay. The **test is the spec** ([verification](verification.md)).
- **Heavy path** — risky, architectural, or hard-to-reverse work: a real spec + a [decision](the-atom.md) + a
  review checkpoint.
- The human can always pull a task up to the heavy path; an agent must escalate an ambiguous one.

**Why:** [pains P2/P3/P5](../research/vibin-painpoints.md) — fixed-template ceremony gave a one-line fix the
same 587-line treatment as an engine change. Match effort to stakes. See also
[the conversational track](the-conversational-track.md).
